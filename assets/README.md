# Logos

The first time you run the Label Studio it asks for two images and saves them here:

- `logo-header.*` - the wide Crosby Volkswagen wordmark printed across the top of the label
- `logo-icon.*` - the square VW roundel dropped into the middle of the QR code

PNG with a transparent background works best. To swap them later, open the Label Studio and use
**Label & printing options -> Replace saved logos**, or just drop new files in here with the
same names.
